# The Missing Necklace

A text-based detective game built with Python.

## About

A valuable necklace mysteriously disappears from a mansion during a dinner party.

You play as the detective investigating the case. Search different rooms, discover clues, interview suspects, compare their statements, and determine who is responsible for the missing necklace.

## How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/Anthoniaokoye-ogbunobi/the-missing-necklace.git
```

Move into the project folder:

```bash
cd the-missing-necklace
```

Run the game:

```bash
python3 main.py
```

## Game Features

* Investigate different rooms
* Discover clues
* Interview suspects
* Compare evidence and statements
* Make an accusation
* Win or lose based on your investigation
